# Mandate

Mandate records bounded authorization evidence for a principal, digest, expiry, and allowed call selectors. The contract does not itself grant wallet authority.

Testnet deployment and explorer proof: [BOTCHAIN_TESTNET.md](BOTCHAIN_TESTNET.md).

This repository publishes the contract layer only. No public web app URL, signed live authority grant, or mainnet deployment is claimed.

```sh
forge build
forge test
```
